# 测试规范

> Engineering Playbook 子文档（保留原编号 §10）。适用场景：测试设计、测试执行、测试门禁。

## 10. 测试规范（ISO/IEC/IEEE 29119）

- **测试目录镜像源码结构**；命名 `<module>_test` / `<module>.spec`。
- **单元测试零外部依赖**：框架/领域层测试只依赖被测模块 + 标准库，**在边界 mock 第三方**（torrent 库、HTTP、DB），保证快、稳、可并行。
- **集成测试**用真实依赖夹具（内存 DB/本地 server fixture）验证模块协作。
- **E2E + 基线快照**：对外接口录"期望响应快照"（`baseline/endpoints.json`），脚本比对实际 vs 期望，回归立刻可见。
- **预提交门禁**：`编译零告警 → 单测全过 → 冒烟/E2E 通过`，任一不过不得合并。
- 每个数据结构/算法/状态机都应有对应单测；修 bug 先补能复现的测试。
