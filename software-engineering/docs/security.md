# 安全规范

> Engineering Playbook 子文档（保留原编号 §9）。适用场景：安全加固、凭据管理、权限/鉴权设计。

## 9. 安全规范（ISO/IEC 27001 思想）

- **凭据永不入库**：私钥/token/密码 MUST NOT 进版本库；私钥**每设备新生成**，仓库只存公钥/非敏感配置。
- **默认排除而非默认包含**：导出/同步时按"脱敏/排除清单"过滤，敏感项默认不带；确需同步走独立安全通道。
- **机密走配置外**：密码/密钥经环境变量或密钥库注入，不写进代码与提交的配置文件。
- **鉴权与 RBAC**：受保护端点经鉴权中间件校验 token；区分普通/管理员权限，管理操作单独门控。
- **输入严格校验**：外部输入（地址、JSON、查询参数）经校验中间件清洗；保存前先做**连通性/有效性测试，通过才生效**。
- **完整性校验**：下载产物 `sha256` 校验，防污染。
- **最小权限 + 集中提权**：仅在确需处提权，一次性、集中、可审计。
- **高危操作多重确认**：破坏性操作（重置/清库）要求多重确认（多次警告 + 输入确认短语）。
