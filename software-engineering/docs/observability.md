# 可观测性 / 日志

> Engineering Playbook 子文档（保留原编号 §8）。适用场景：日志设计、排障、可观测性建设。
> 目标：每次运行可复盘；故障可定位；用户看得见失败并可重试。

## 8. 可观测性 / 日志（Observability）

### 8.1 三大支柱（按需裁剪）

| 支柱 | 用途 | A 档 | B 档 |
|------|------|------|------|
| **Logs** | 事件序列、错误上下文 | 必做 | 必做 |
| **Metrics** | 延迟、错误率、队列深度、资源 | 可选 | 对外服务 SHOULD |
| **Traces** | 跨模块/跨进程请求链 | 可选 | 分布式/多服务 SHOULD |

未做 Metrics/Traces 时，用结构化日志 + 结束汇总兜底，并在 DESIGN 声明观测边界。

### 8.2 日志架构

- **集中式日志器**：一个 `LoggerPool` / `AppLogger`，**按模块取命名 logger**（每个 app/模块一个），统一格式与级别。
- **分级**：Trace / Debug / Info / Warning / Error / Fatal（按需）；级别**可配置**，生产默认 Info+。
- **多 sink + 轮转**：文件 + 控制台/stderr；文件按大小或时间轮转（如 5–10 MB 或每日）；保留份数有上限。
- **结构化 + 人读双轨**：
  - 机器：JSONL（时间、level、logger、msg、字段、error、trace_id）
  - 人：控制台友好输出；批处理结束输出 `ok / skip / fail` 汇总

### 8.3 必记节点

以下 MUST 有日志（或等价指标）：

1. **启动**：版本、配置路径、监听端口/模式、特性开关摘要
2. **关闭**：信号来源、优雅停机各阶段、是否超时强杀
3. **外部 IO**：出站请求（目标、耗时、状态码/错误码）；入站关键写操作
4. **所有错误**：含可关联的 request/correlation id；堆栈在 Error+（注意脱敏）
5. **幂等跳过**：detect 判定已满足而 skip 时记 Info，便于审计「为何没改」

### 8.4 Correlation / 上下文

- 每个请求或一次 CLI 运行分配 `correlation_id` / `run_id`，贯穿日志字段。
- 异步任务继承或派生 id，避免「孤儿」错误日志无法归案。
- HTTP：接受并回传 `X-Request-Id`（或项目约定头）。

### 8.5 用户可见反馈

- UI 经通知服务（snackbar / toast / 对话框）报错；**关键失败给可重试入口**。
- 用户文案走 i18n；技术细节放「详情/日志」展开，默认不惊吓用户。
- CLI：stderr 简明错误 + 非零退出码；`--verbose` 才打 Debug。

### 8.6 PII 与安全

- 凭据 / 令牌 / 密钥 MUST 掩码（如 `tok***`）。
- 邮箱、电话、精确定位等按项目脱敏清单处理；诊断包默认排除明文 PII。
- 禁止把整份请求体（可能含密码）打进 Info 日志。

### 8.7 Metrics 最小集（B 档建议）

- 请求/任务：**计数、错误计数、延迟直方图**（p50/p95）
- 资源：队列长度、线程池占用、磁盘/句柄（按产品相关选）
- 业务：关键成功转化（如下载完成数）—— 只留真正用于告警/容量的

告警阈值写进运维文档或 DESIGN：错误率、p95 延迟、队列堆积。

### 8.8 Traces（可选）

- 跨进程用 W3C Trace Context 或项目等价物。
- Span 名稳定、低基数；禁止把高基数 user id 放进 span 名。
- 采样率可配；错误请求 SHOULD 提高采样。

### 8.9 排障检查清单

- [ ] 能从一次失败用户报告定位到 `correlation_id` / 时间窗
- [ ] 启动/关闭/外部错误有结构化字段
- [ ] 日志无明文密钥；轮转与磁盘上限有效
- [ ] 批处理结束有 ok/skip/fail 汇总
- [ ] （B）关键路径有延迟/错误指标或等价日志可聚合
- [ ] UI/CLI 失败可重试且错误可理解

### 8.10 反模式

- 用 `print` / `Console.WriteLine` 散落代替统一 logger
- 只打「失败」不打上下文（无输入摘要、无错误码、无耗时）
- 在热路径打 Trace 且无法关闭，拖垮性能
- 日志与指标同名混乱、无命名规范导致无法检索
