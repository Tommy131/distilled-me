# 可观测性 / 日志

> Engineering Playbook 子文档（保留原编号 §8）。适用场景：日志设计、排障、可观测性建设。

## 8. 可观测性 / 日志（Observability）

- **集中式日志器**：一个 `LoggerPool`/`AppLogger`，**按模块取命名 logger**（每个 app/模块一个），统一格式。
- **分级**：Trace/Debug/Info/Warning/Error/Fatal（按需），级别**可热调**。
- **多 sink + 轮转**：文件 sink + 控制台/stderr sink，可插拔；文件**自动按大小轮转**（如 5–10 MB），自动捕获堆栈。
- **结构化 + 人读双轨**：机器可解析（JSONL）用于排障，控制台友好输出 + 结束 `ok/skip/fail` 汇总用于人看。
- **关键节点必记**：启动（版本/配置路径/监听端口）、关闭（优雅停机阶段）、每次外部请求、所有错误。
- **用户可见反馈**：UI 经通知服务（snackbar/toast/对话框）报错，关键失败给可重试入口 + 可展开日志。
- **PII 脱敏**：日志中凭据/令牌/密钥 MUST 掩码（如 `tok***`）；用户个人数据（邮箱/电话等）按 §9 脱敏清单处理，诊断日志不记录明文。
